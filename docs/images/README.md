# 截图目录

README 顶部引用了下面 3 张图。把截图放进本目录、**文件名保持一致**，然后把 `README.md` 顶部那段 HTML 注释里的三行取消注释即可。

| 文件名 | 建议截取的内容 | 想展示什么 |
|---|---|---|
| `main.png` | 主界面：中文提问 → 图表 + 中文结论 | 一句话取数出图 |
| `sql.png` | 展开「查看生成的 SQL」+ 结果表 | **取数过程可核对**（差异化） |
| `alerts.png` | 智能预警：扫描结果列表（含分级与「深入归因」入口） | 主动发现异常 |

取消注释后，`README.md` 顶部应该是这样：

```markdown
![主界面问答](docs/images/main.png)
![SQL 与图表](docs/images/sql.png)
![异常预警](docs/images/alerts.png)
```

建议：宽度 1200~1600px、PNG、单张控制在 300KB 以内（仓库不宜过大）。
